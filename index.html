Cómo usar IBB Música

  1. Selecciona una alabanza para ver la letra y los acordes.
  2. Usa “− Tono” y “+ Tono” para adaptar la tonalidad.
  3. Para agregar una canción, pulsa “Añadir alabanza” y pega la letra completa con los acordes entre corchetes.
  4. Los cambios se guardan en este navegador. Para compartir el repertorio con el equipo, usa Exportar respaldo y luego Importar respaldo en cada dispositivo.

Importante: por ahora los datos se guardan localmente en cada dispositivo; no se sincronizan automáticamente entre músicos. No incluyas información privada.
